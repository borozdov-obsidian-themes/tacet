# Borozdov Tacet

A theme from the Borozdov collection. Two faces — light **Lull**, type and silence on warm
paper, and dark **Umbra**, the same page with the lamp turned low. Two inks, graphite for
the text and near-black for what matters, and no cards, boxes or colour at all.

![Borozdov Tacet in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/tacet/main/screenshots/light.png)

![Borozdov Tacet in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/tacet/main/screenshots/dark.png)

## Principles

- **Two inks.** Graphite for running text; near-black for headings, bold, links, the open
  file and the one filled button.
- **No boxes.** A callout is an icon and a title with the text hung from the same margin;
  code is told apart by its monospace and an indent; tables keep only the rules between
  rows.
- **One surface.** The same warm paper for the note, the side panels and the tab strip,
  separated by a single hairline.
- **A book-like measure.** With readable line length on, the text keeps a narrower column
  with generous leading.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts, code blocks and embeds without boxes or fills
- Tables ruled between rows only
- Tags as plain graphite text
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Tacet**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the [latest
release](https://github.com/borozdov-obsidian-themes/tacet/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Tacet/`, then choose Borozdov Tacet under Settings →
Appearance → Themes.
